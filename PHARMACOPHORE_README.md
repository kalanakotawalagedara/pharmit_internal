# Interaction Pharmacophore Generator

Automated system for generating protein-ligand interaction pharmacophore models from PDB structures, optimized for future triangle decomposition-based searching.

## Overview

This system processes PDB structures and generates pharmacophore models representing **validated protein-ligand interactions only**. Features without complementary receptor interactions are automatically filtered out.

### Key Features

- **Interaction-based filtering**: Only includes ligand features with validated receptor interactions
- **Water-mediated binding**: Considers binding site waters as receptor atoms during interaction detection
- **Directional vectors**: H-bond donors/acceptors include vectors pointing to receptor partners
- **Pharmit-compatible**: Uses exact SMARTS patterns and interaction rules from Pharmit codebase
- **GitHub Actions ready**: Scalable batch processing for large datasets
- **Incremental processing**: Skips already-processed entries for resumability

## Pharmacophore Feature Types

Based on Pharmit's default definitions (`pharmarec.cpp`):

1. **Aromatic** - 6/5-membered aromatic rings
2. **HydrogenDonor** - NH, OH, SH groups (with vector to receptor acceptor)
3. **HydrogenAcceptor** - N, O atoms (with vector to receptor donor)  
4. **PositiveIon** - Charged nitrogens, amidines, guanidines
5. **NegativeIon** - Carboxylates, phosphates, sulfonates
6. **Hydrophobic** - Aromatic rings, aliphatic chains, halogens

## Interaction Rules

| Ligand Feature | Receptor Partner | Max Distance | Min Matches |
|----------------|------------------|--------------|-------------|
| Aromatic | Aromatic | 5.0 Å | 1 |
| HydrogenDonor | HydrogenAcceptor | 4.0 Å | 1 |
| HydrogenAcceptor | HydrogenDonor | 4.0 Å | 1 |
| PositiveIon | NegativeIon | 5.0 Å | 1 |
| NegativeIon | PositiveIon | 5.0 Å | 1 |
| Hydrophobic | Hydrophobic | 6.0 Å | 3 |

## Input Format

CSV file with columns:
```csv
PDB_ID,Ligand_Name
1A52,EST
2HYY,STI
6LU7,PRD_002214
```

- **PDB_ID**: 4-character PDB identifier
- **Ligand_Name**: 3-letter ligand residue name (as in PDB HETATM records)

## Output Format

One JSON file per PDB-ligand pair: `{PDB_ID}_{Ligand_Name}.json`

```json
{
  "pdb_id": "1A52",
  "ligand_name": "EST",
  "ligand_chain": "A",
  "processing_date": "2026-04-12T10:30:00Z",
  "num_features": 3,
  "features": [
    {
      "type": "Aromatic",
      "x": 106.932,
      "y": 16.930,
      "z": 100.366,
      "radius": 1.0,
      "atom_indices": [1, 2, 3, 4, 5, 6]
    },
    {
      "type": "HydrogenDonor",
      "x": 106.801,
      "y": 19.239,
      "z": 100.813,
      "radius": 1.0,
      "atom_indices": [3],
      "vector": {
        "x": 0.577,
        "y": -0.577,
        "z": 0.577
      }
    }
  ],
  "metadata": {
    "ligand_atoms": 20,
    "receptor_atoms": 2847,
    "screened_out_features": 2
  }
}
```

### JSON Fields

- **features**: Only includes validated interaction features
- **vector**: Unit vector for H-bond donors/acceptors (pointing from ligand to receptor partner)
- **atom_indices**: Atom indices from ligand molecule (for debugging)
- **screened_out_features**: Number of ligand features excluded (no receptor complementarity)

## Usage

### Local Execution

```bash
# Install dependencies
conda create -n pharmacophore python=3.10
conda activate pharmacophore
conda install -c conda-forge rdkit pandas numpy requests

# Run on full CSV
python generate_pharmacophores.py --csv Input/pdb_ligands.csv --output Output

# Run on specific batch (for parallelization)
python generate_pharmacophores.py \
  --csv Input/pdb_ligands.csv \
  --output Output \
  --batch-start 0 \
  --batch-size 1000
```

### GitHub Actions

1. Navigate to **Actions** tab in your repository
2. Select **"Generate Interaction Pharmacophores"** workflow
3. Click **"Run workflow"**
4. Configure parameters:
   - **csv_file**: Path to CSV (default: `Input/pdb_ligands.csv`)
   - **batch_size**: Entries per job (empty = process all in single job)
   - **num_batches**: Number of parallel jobs (empty = single job, 1-20 for parallel)

#### Example Configurations

**Small dataset (<100 entries):**
```
csv_file: Input/pdb_ligands.csv
batch_size: (empty)
num_batches: (empty)
```

**Large dataset (200k entries):**
```
csv_file: Input/pdb_ligands.csv
batch_size: 1000
num_batches: 20
```
This processes 200 batches × 1000 entries each in 20 parallel jobs.

5. Download results from **Artifacts** section:
   - `pharmacophores-complete` - All generated JSON files + index
   - `processing-summary` - Error logs and statistics

## Triangle Decomposition Preparation

The JSON output is optimized for future triplet-based searching:

### Next Steps for Search Engine

1. **Triplet Generation**: For each pharmacophore, generate all C(n,3) triplets from n features
2. **Geometric Invariants**: Calculate distances (d1, d2, d3) and feature type triplet
3. **KD-Tree Indexing**: Index triplets by geometric properties for fast range queries
4. **Query Matching**: Use recursive backtracking to find consistent correspondences

### Suggested Database Schema

```python
# Triplet representation
{
  "pharmacophore_id": "1A52_EST",
  "triplet_id": 0,
  "feature_indices": [0, 1, 2],
  "feature_types": ["Aromatic", "HydrogenDonor", "HydrogenAcceptor"],
  "distances": [5.2, 6.1, 4.3],  # sorted
  "centroi	d": [106.5, 17.2, 98.5]
}
```

## Error Handling

- **PDB download failures**: Logged and skipped
- **Ligand not found**: Logged with chain information
- **Zero interaction features**: Valid output (empty features array)
- **Incremental mode**: Already-processed entries are automatically skipped

## Performance

- **Single entry**: ~2-5 seconds
- **1000 entries** (sequential): ~50-80 minutes
- **1000 entries** (20 parallel batches): ~5-10 minutes
- **Memory**: ~500MB per job

## Troubleshooting

### Common Issues

**"Failed to parse ligand PDB"**
- Check ligand name matches PDB HETATM records exactly
- Some ligands use non-standard residue names

**"Zero interaction features"**
- Ligand has no features with complementary receptor partners
- Check if ligand is crystallization artifact (PEG, GOL, etc.)

**"Timeout downloading PDB"**
- RCSB server may be slow
- Retry or use local PDB mirror
